# 📊 Social Media Addiction & Well-Being Analysis

## 📌 Project Overview

This project analyzes social media usage patterns and their relationship with
sleep, academic performance, demographics, and overall well-being.

The analysis was developed in Excel using data cleaning, Pivot Tables,
Pivot Charts, KPI analysis, interactive filters, and dashboard visualization.

## 🎯 Project Objectives

- Analyze daily social media usage patterns
- Identify the most-used social media platforms
- Examine the relationship between social media usage and sleep
- Analyze age and country-wise patterns
- Understand relationship-status distribution
- Examine academic performance patterns
- Compare usage across education levels

## 🛠️ Tools & Techniques

- Data Cleaning

## 🔍 Key Analysis Areas

### Social Media Usage
Analysis of average daily usage and the most popular social media platforms.

### Sleep & Usage
Comparison of social media usage with average sleep hours across age groups.

### Demographics
Analysis of age distribution, countries, education levels, and relationship status.

### Academic Performance
Analysis of the relationship between social media usage and academic performance.

## 💡 Key Insights

- Social media usage varies significantly across users.
- The dashboard highlights the most frequently used social media platforms.
- Sleep patterns can be compared against social media usage across different age groups.
- Demographic analysis provides insights into usage patterns across countries and age groups.
- Academic performance can be evaluated alongside social media behavior.
